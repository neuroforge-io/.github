# NeuroForge

Tools for working with language, knowledge and AI. [neuroforge.io](https://neuroforge.io/)

Public projects from NeuroForge and Lloyd Handyside:

- **[Word Forge](https://github.com/Ace1928/word_forge)** — Word relationships, semantic graphs and lexical search.
- **[Glyph Forge](https://github.com/Ace1928/glyph_forge)** — Turn images, text and video into character art.
- **[RKC](https://github.com/neuroforge-io/RKC)** — Searchable knowledge from folders, repositories and docs, with citations back to the source.
- **[Sinter](https://github.com/neuroforge-io/Sinter)** — A free, local-first workbench for community funding research, meeting records and handovers. The current published desktop preview is for Linux.
- **[Minecraft AI](https://github.com/Ace1928/minecraft_ai)** — Experimental Minecraft agent work, with vision, planning and memory.

Feedback, bug reports and contributions are welcome in the project repositories.
